# Ejercicios de Programación en Python

Este repositorio contiene una colección de **ejercicios prácticos de programación en Python**, organizados según las diferentes unidades didácticas trabajadas durante el curso.

El objetivo es aplicar de forma práctica los conceptos aprendidos en cada tema mediante diferentes ejercicios y pequeños programas.

---

## Contenido

| Unidad | Tema                                | Contenido                                                |
| :----: | ----------------------------------- | -------------------------------------------------------- |
|   UD2  | Programación estructurada en Python | Fundamentos de Python, condicionales, bucles y funciones |
|   UD3  | Estructuras de datos                | Listas, tuplas, diccionarios, conjuntos y matrices       |
|   UD4  | Programación Orientada a Objetos    | Objetos, clases y uso de la biblioteca estándar          |
|   UD5  | Clases                              | Atributos, métodos, constructores y sobrecarga           |
|   UD6  | Ficheros                            | Lectura, escritura, CSV y JSON                           |
|   UD7  | Interfaces gráficas                 | Desarrollo de interfaces mediante Tkinter                |
|   UD8  | Desarrollo de aplicaciones con BDOO | Bases de datos orientadas a objetos y ZODB               |

---

## UD2 - Programación estructurada en Python

En esta unidad se trabajan los fundamentos del lenguaje Python y los principales elementos de la programación estructurada.

### Contenidos

* Variables y tipos de datos.
* Operadores aritméticos, relacionales y lógicos.
* Entrada y salida de datos.
* Estructuras condicionales:

  * `if`
  * `if-else`
  * `if-elif-else`
* Estructuras `match`.
* Bucles:

  * `while`
  * `for`
* `break`.
* Funciones.
* Ámbito de las variables.
* Excepciones.
* Aserciones.
* Operadores de asignación.
* Asignación múltiple.
* Operador ternario.
* Notaciones propias de Python.

Los ejercicios de esta unidad permiten practicar la lógica de programación y los fundamentos del lenguaje.

---

## UD3 - Estructuras de datos

Esta unidad está centrada en las principales estructuras de datos disponibles en Python.

### Contenidos

* Listas.
* Slicing.
* Comprensiones de listas.
* Matrices y listas de listas.
* Tuplas.
* Diccionarios.
* Conjuntos.

Los ejercicios permiten practicar la creación, modificación, recorrido y manipulación de diferentes estructuras de datos.

---

## UD4 - Programación Orientada a Objetos

En esta unidad se introduce la Programación Orientada a Objetos y el trabajo con objetos en Python.

### Contenidos

* Creación de objetos.
* Utilización de objetos.
* Clases.
* Atributos.
* Métodos.
* Clases de la biblioteca estándar.
* Uso de `datetime`.
* Trabajo con listas de objetos.
* Comparación de objetos.
* Búsqueda de objetos.

Los ejercicios permiten comenzar a utilizar objetos para representar diferentes elementos dentro de los programas.

---

## UD5 - Clases

Esta unidad profundiza en la creación y utilización de clases propias en Python.

### Contenidos

* Creación de clases.
* Constructores mediante `__init__`.
* Atributos.
* Métodos.
* Método `__str__`.
* Sobrecarga de operadores.
* `dataclass`.
* Agregación de objetos.
* Colecciones de objetos.

Los ejercicios de esta unidad permiten desarrollar programas utilizando clases y objetos para resolver diferentes problemas.

---

## UD6 - Ficheros y gestión de datos

Esta unidad está dedicada a la lectura, escritura y gestión de información mediante diferentes tipos de ficheros.

### Contenidos

* Ficheros de texto.
* Lectura de ficheros.
* Escritura de ficheros.
* Ficheros de configuración.
* Formato CSV.
* Formato JSON.
* Lectura de datos estructurados.
* Conversión de datos a objetos Python.

Los ejercicios permiten trabajar con información almacenada externamente y utilizarla posteriormente desde Python.

---

## UD7 - Interfaces gráficas

En esta unidad se trabaja el desarrollo de interfaces gráficas mediante `Tkinter`.

### Contenidos

* Creación de ventanas.
* Etiquetas.
* Botones.
* Campos de entrada.
* Eventos.
* Organización de elementos.
* `pack()`.
* `grid()`.
* Diferentes pantallas.
* Gestión del estado de una aplicación.
* Ficheros de configuración.
* Desarrollo de aplicaciones gráficas.

Los ejercicios permiten crear interfaces gráficas progresivamente más completas.

---

## UD8 - Desarrollo de aplicaciones con BDOO

Esta unidad introduce las Bases de Datos Orientadas a Objetos y su utilización desde Python.

### Contenidos

* Introducción a las Bases de Datos Orientadas a Objetos.
* Almacenamiento de objetos.
* Relaciones entre objetos.
* ZODB.
* Entornos virtuales de Python.
* Instalación de ZODB.
* Creación de aplicaciones con ZODB.
* Persistencia de objetos.

Los ejercicios permiten desarrollar aplicaciones capaces de almacenar y recuperar objetos utilizando ZODB.
